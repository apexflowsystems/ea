Installation guide

Step-by-step setup for MetaTrader 4 and 5. Estimated time: 15–30 minutes.

  1. Download your EA file

    After payment is confirmed, we email the .ex5 file and license key. Keep them safe.

  2. Open MetaTrader 5 data folder

    In MT5: File → Open Data Folder. This opens the MQL5 directory.

  3. Copy EA to Experts folder

    Navigate to MQL5/Experts/ and paste your .ex5 file.

  4. Enable automated trading

    Tools → Options → Expert Advisors. Check Allow automated trading and Allow DLL imports (required for license validation). Click OK.

  5. Attach EA to chart

    Open an XAUUSD chart (M1 or M5). From Navigator, drag SMElite onto the chart.

  6. Enter your license key

    In the inputs tab, paste your license key exactly. Set risk parameters, then click OK.

  7. Verify the smiley face

    A green smiley (or AutoTrading label) should appear top-right. Sad face = recheck auto-trading and DLL imports.

  8. Monitor the dashboard

    Confirm status, positions, and equity display correctly before leaving the terminal unattended.

VPS tip: For 24/5 operation use a VPS (London or NY recommended). Minimum 2 GB RAM, stable connection. Same install steps apply over Remote Desktop.
Broker digits (PIP inputs): Brokers differ on decimal places for XAUUSD. Example: Exness often uses 3 decimal digits; IC Markets may use a different format. On 3-decimal brokers, PIP-related input values usually need an extra trailing zero (…0) so distances match the chart (a value that works as 10 on a 2-decimal feed may need 100 on a 3-decimal feed — confirm on your symbol). Check Market Watch → symbol → Specification for Digits / Point, then align all PIP / point inputs. Test on demo first.
Min profit close vs lot size: For input int InpMinProfitClose = 2; (and similar money targets), scale the minimum with lot size — add a trailing 0 for every 10× increase in lot. Example: 0.01 lot → about $2; 0.1 lot → about $20; 1.0 lot → about $200. Keep the ratio consistent so profit targets stay proportional to position size.
